# موقع الرهوان السريع

موقع بسيط (4 صفحات) لخدمات نقل وتركيب الأثاث، جاهز للنشر مجانًا على GitHub Pages.

## الملفات
- `index.html` — الرئيسية
- `services.html` — خدماتنا
- `about.html` — من نحن
- `contact.html` — تواصل معنا (فيه نموذج طلب عرض سعر يفتح واتساب تلقائيًا)
- `css/style.css` — التصميم
- `js/main.js` — قائمة الجوال + نموذج التواصل
- `assets/images/logo.png` — الشعار

## طريقة النشر على GitHub Pages (مجانًا)

1. أنشئ حساب على github.com إذا لم يكن لديك واحد.
2. أنشئ مستودع (Repository) جديد باسم مثلاً: `alruhwan-alsari3`.
   - اجعله **Public**.
3. ارفع كل الملفات الموجودة في هذا المجلد إلى المستودع (يمكنك السحب والإفلات من صفحة المستودع على GitHub مباشرة، أو استخدام Git).
4. اذهب إلى: **Settings → Pages**.
5. تحت "Build and deployment" اختر:
   - Source: **Deploy from a branch**
   - Branch: **main** والمجلد: **/ (root)**
6. احفظ، وانتظر دقيقة أو دقيقتين.
7. سيظهر رابط موقعك بالشكل:
   `https://اسم-المستخدم.github.io/alruhwan-alsari3/`

## لاستبدال الصور بصور فريقك الحقيقية
- ضع صورك داخل مجلد `assets/images/`
- عدّل مسار الصورة داخل ملفات HTML (مثال: `<img src="assets/images/logo.png">`)

## لتغيير رقم الواتساب
ابحث عن الرقم `966552466534` في كل الملفات (index.html, services.html, about.html, contact.html, js/main.js) واستبدله برقمك الجديد بصيغة دولية بدون + أو أصفار في البداية.

## لاحقًا: ربط دومين خاص
عند شراء دومين (مثال: alruhwan.com)، أضف ملف باسم `CNAME` في جذر المشروع يحتوي فقط على اسم الدومين، ثم اربط الدومين من مزود الدومين نحو GitHub Pages.
